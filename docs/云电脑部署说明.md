## 0. 一句话原理

本地那套脚本**路径无关 + 纯标准库**（用 `os.path.dirname(os.path.abspath(__file__))` 定位自身目录，
只 import `urllib/json/os/time/datetime`），所以**不需要改代码**，
只要把整个文件夹传上去、装个 python3、挂一条 crontab 就能跑。

推送通道不变，仍走 **Server酱**（密钥已随 `数据/notify_config.json` 一起打包）。

## 1. 要上传什么

上传 `payload/fund-monitor/` 这**整个文件夹**：

```
fund-monitor/
├── monitor.py              # 巡检：拉净值、算偏差、判触发
├── notify.py               # 读 trigger.json，推 Server酱
├── 生成看板.py              # 生成 看板.html
├── run.py                  # Windows 侧一键跑（云上不用）
├── run.sh                  # ★ 云电脑侧一键跑
├── crontab.txt             # ★ 定时任务模板
├── 说明.md                  # 完整使用说明
├── 数据/
│   ├── nav_080006.json     # 已积累的净值缓存 —— 带上可省一次全量拉取
│   ├── nav_270042.json     # 同上
│   └── notify_config.json  # 推送通道配置（Server酱 key 在里面）
└── 日志/                   # 空目录，运行后自动写入
```

**注意**：`数据/` 一定要带上，否则首次运行要从东财重新拉净值，多花一两分钟。

## 2. 上传方式（豆包云电脑）

云电脑是**独立 Linux 实例，读不到你本机任何文件**，必须走上传。两条路：

- **A. 云电脑带文件上传入口**：直接选文件夹上传，落到 `/root/` 下。
- **B. 没有上传入口时**：本机起个临时 HTTP 服务，云电脑 `wget` 下来。
  本机（Windows，Git Bash）：
  ```bash
  cd "E:/ai/基金漂移监控/云电脑部署/payload"
  python -m http.server 8000
  ```
  云电脑：
  ```bash
  cd /root && wget http://<你本机内网IP>:8000/fund-monitor.zip && unzip fund-monitor.zip
  ```
  ⚠️ 这要求两边网络互通，云电脑通常在外网，**大概率走不通**，优先用方式 A。

最终目标位置：**`/root/fund-monitor/`**

## 5. 挂定时任务

先确认**云电脑时区**：

```bash
date
```

- 显示 `CST`（+0800）：用 `0 4 * * *` —— 北京 04:00 跑。
- 显示 `UTC`：用 `0 20 * * *` —— 即北京次日 04:00。

挂载：

```bash
apt install -y cron
service cron start
( crontab -l 2>/dev/null; echo "0 4 * * * cd /root/fund-monitor && /bin/bash run.sh" ) | crontab -
crontab -l        # 确认已写入
```

> 若云电脑**没有 cron / 不允许常驻服务**，改用云电脑自带的「定时任务」功能，
> 动作填：`cd /root/fund-monitor && bash run.sh`

| 看什么 | 在哪 |

想看时把 `看板.html` 从云电脑下载回本机，双击打开。

## 7. 补跑机制

脚本每次运行都会**全量拉最新净值并与本地缓存合并**，自动补齐上次运行以来落下的所有交易日。

- 即使云电脑某天没跑（休眠、欠费、维护），下次跑照样把缺口补上。
- 补跑日期会写进当天日志与推送正文（形如 `含补跑 3天（2026-09-26~2026-09-28）`）。
- 连续性靠 `数据/last_run.txt` 记录上次运行日，**这个文件不要删**。

## 10. 故障速查

| 现象 | 原因 | 处理 |
|---|---|---|
| `未找到 python3` | 没装 | `apt install -y python3` |
| 401 / 403 抓不到净值 | 东财接口偶发限流 | 脚本已带 Referer 与重试，隔几分钟再跑 |
| Server酱返回 `code!=0` | key 失效 / 当日推送上限 | 去 sct.ftqq.com 换 key，改 `数据/notify_config.json` |
| 日志里 emoji 变问号 | 终端 locale | 无影响，只是显示，数据正常 |
| 一直无推送 | 未触发（正常） | 用第 4 步的测试命令验证通道 |
| cron 不跑 | cron 服务未启动 | `service cron start`，或改用云电脑自带定时任务 |
